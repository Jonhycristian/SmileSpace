# SmileSpace Odontologia - Landing Page

Bem-vindo ao repositório do projeto **SmileSpace**, uma clínica odontológica especializada em implantes, próteses e estética dental localizada em Belo Horizonte.

## 🦷 Sobre o Projeto

Esta é uma Landing Page otimizada e de alta performance criada para atrair e converter pacientes para a clínica SmileSpace. O site foi desenvolvido com tecnologias puras (HTML, CSS e JavaScript), garantindo carregamento rápido, excelente SEO e uma experiência de usuário (UX) premium.

### 🌟 Destaques da Landing Page:
- **Design Premium e Responsivo:** Cores sofisticadas (Preto, Branco, Dourado) e design adaptável para celulares e computadores.
- **Otimização de SEO Avançada:** 
  - Tags estruturadas (JSON-LD para LocalBusiness/MedicalClinic).
  - Open Graph e Twitter Cards para compartilhamento enriquecido nas redes sociais.
  - Otimização rigorosa de `title`, `meta descriptions` e `alt` de imagens com foco em palavras-chave ("Implantes em BH", "Dentista BH").
  - Ausência de conteúdo duplicado.
- **Integração com WhatsApp:** Botões flutuantes e links de agendamento que direcionam automaticamente o paciente para uma conversa de WhatsApp.
- **Acessibilidade:** Marcação semântica e boas práticas de UX.
- **Seção de Vídeos (Estilo Reels):** Galeria de vídeos responsiva focada na imersão do paciente e apresentação da clínica.

## 🛠 Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e SEO friendly.
- **CSS3:** Estilização utilizando Vanilla CSS com variáveis para manter a flexibilidade de temas, garantindo excelente tempo de carregamento sem dependências pesadas de bibliotecas de terceiros.
- **JavaScript (Vanilla):** Para animações sutis, carrosséis, modals e controle de vídeos.
- **Fontes Google:** Montserrat e Playfair Display.
- **FontAwesome:** Biblioteca de ícones.

## 📂 Estrutura de Arquivos Principais

- `index.html`: Página principal da clínica com carrossel, lista de serviços, corpo clínico e contato.
- `atendimento.html`: Página secundária focada exclusivamente em roteamento de agendamento de consultas via WhatsApp.
- `drgabrielbarbosa.html`: Página de perfil digital e link na bio dedicada ao Dr. Gabriel Barbosa.
- `drherbertfelipe.html`: Página de perfil digital e link na bio dedicada ao Dr. Herbert Felipe.
- `/img`: Pasta contendo todas as imagens e mídias visuais do site.

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Jonhycristian/SmileSpace.git
   ```
2. Abra a pasta do projeto no seu computador.
3. Abra o arquivo `index.html` em qualquer navegador moderno.
